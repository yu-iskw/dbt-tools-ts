# RFCs

Request-for-comments documents for **large, cross-package design proposals** in dbt-tools-ts.

- An **RFC** proposes a design and invites review; it may be revised while under discussion.
- An **ADR** ([`docs/adr/`](../adr/)) records a decision that has been accepted and its durable invariants.
- When an RFC (or a slice of it) is accepted and implemented, the durable decisions are distilled into one or more ADRs; the RFC remains as design rationale and is not kept up to date afterward.
