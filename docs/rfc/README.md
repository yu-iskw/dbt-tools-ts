# Request for Comments (RFC)

RFCs propose substantial design changes for dbt-tools. Accepted RFC invariants are distilled into [ADRs](../adr/README.md).

| RFC | Status | Title |
| --- | ------ | ----- |
| [RFC-0001](./RFC-0001-clean-slate-redesign.md) | Proposed | Clean-slate redesign — architecture, security, and governance |

## Process

1. **RFC proposes** — design thought experiment or migration roadmap in `docs/rfc/`.
2. **ADR records** — durable invariants land in `docs/adr/` after implementation or acceptance.
3. Current ADRs remain in force until superseded by a newer ADR.
