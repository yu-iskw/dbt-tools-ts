# Troubleshooting

## Common Issues

### "Cannot find manifest.json"

**Symptom:** The tool exits with an error about a missing or unreadable manifest file.

**Cause:** The `--dbt-target` (or `--target`) path does not point to a directory containing `manifest.json`.

**Fix:** Run `dbt compile` or `dbt run` in your dbt project first, then point to the generated `target/` directory:

```bash
cd my-dbt-project
dbt run
npx @dbt-tools/cli status --dbt-target ./target
```

### "Unsupported manifest version"

**Symptom:** The tool reports that the manifest schema version is not supported.

**Cause:** The `manifest.json` was generated by a dbt version whose schema is not yet supported by `dbt-artifacts-parser`.

**Fix:** Check the dbt-artifacts-parser changelog for supported dbt versions. You may need to update your dbt version or wait for a parser update.

### MCP Server Not Connecting

**Symptom:** Your MCP client cannot connect to the dbt-tools MCP server.

**Cause:** The server may not be running, or the client configuration points to the wrong command.

**Fix:** Verify the server starts correctly:

```bash
npx @dbt-tools/mcp --dbt-target ./target
```

Then check your MCP client configuration uses the correct command and arguments.

### Web UI Shows Stale Data

**Symptom:** The browser UI displays old run results after you've run dbt again.

**Cause:** The web server reads artifacts at startup and does not watch for file changes by default.

**Fix:** Restart the web server after each dbt run to load fresh artifacts.
