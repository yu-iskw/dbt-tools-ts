# Agents and plugins

First-party **coding agent skills** for dbt-tools live under [`plugins/`](https://github.com/yu-iskw/dbt-tools-ts/tree/main/plugins) in the repository.

End-user documentation for installing marketplaces and using skills (for example `dbt-tools-cli:status`) is **planned for this site**.

For now, see the repository [plugins README](https://github.com/yu-iskw/dbt-tools-ts/blob/main/plugins/README.md).

**Typical stack:** `@dbt-tools/cli` or `@dbt-tools/mcp` for artifact access; plugins add workflow skills on top.
